# TKR Al Khobar — Menu

The real menu of Tahir Khan Restaurant, Al Khobar branch (7th Cross, Prince Majid
Street, Al Khobar Al Shamalia, Saudi Arabia), as a bilingual web page — English
with Arabic (RTL), search, and category filters.

- 17 sections, 119 dishes, prices in Saudi Riyals (SAR)
- Prices and dishes are the branch's own printed menu, photographed on Google
  Maps (Menu tab, Nov 2026) and cross-checked against the same menu filmed in a
  customer review video and a customer bill from the branch (13 Nov 2026)
- 6 items have no price anywhere on the menu (four sauces, Mash Potato,
  Sauteed Vegetable) and are shown as "Price to confirm" — nothing is invented
- Reservation number as printed on the menu: 050 900 9474 (phone and WhatsApp)

## Files

- `index.html` — the page (generated, do not edit by hand)
- `build_menu.py` — the data + generator; edit the items there and run
  `python3 build_menu.py` to rebuild
- `assets/` — branch photos: the menu cover, dining hall, opening night,
  the giant platter, the chicken corn soup frame, and the TKR logo

## Status
